# Explain and test any regex, EN + AR

Explain and test any JavaScript regex: live highlighting, capture groups, token-by-token explanation in English or Arabic.

**Live:** https://mostaaafaomran-ctrl.github.io/regexlens/

- Runs fully in the browser, nothing uploaded, no signup
- Plain HTML/CSS/JS, no build step, no dependencies
- Arabic and English

## Run locally
Open `index.html` in a browser.

## Logic tests
`core.js` works in Node: `node -e "console.log(Object.keys(require('./core.js')))"`
